# EasyCook

A family meal picker for iOS and Android, built with Expo (React Native) and Expo Router.

## What it does

- **Pick** — choose a cuisine, which meal, how many days (or "cook once, eat leftovers"), how many people, whether kids are eating, time limit, dietary needs, budget, effort and free-form notes. Then tap **Get meal ideas**.
- **Meal ideas** — one idea per day. For each one you can rate it 1–5 stars, save it to Favorites, swap it, or open/generate a recipe. You can also share the plan with a combined shopping list.
- **Favorites** — a photo gallery of meals your family loved, with ratings, notes, a "we made it again" counter, cuisine filters, sorting and **Surprise me**. Favorites also feed back into the ideas ("Smart mix" or "Favorites only").
- **Recipes** — type your own, have Claude write one for any dish, or start from a photo. Snap a recipe card, cookbook page or the finished dish and Claude fills in the ingredients (and the steps, when they're written down). Everything stays editable.
- **Learning** — star ratings steer future ideas. Meals rated 4–5 come up more often, and meals rated 1–2 are never suggested again.

## AI vs. offline

Without an API key, ideas come from a built-in list of about 55 family meals, filtered and weighted by your ratings. With an Anthropic API key (Settings → AI ideas & recipes), ideas and recipes are generated by Claude Opus 5.5 and personalized with your ratings, favorites and "never suggest" ingredients. The key is stored only on the device, in iOS Keychain / Android Keystore via `expo-secure-store`.

## Running it

```bash
npm install
npx expo start
```

The app uses native modules (secure storage, camera and photo picker, file system), so run it in a development build:

```bash
npx expo run:ios       # needs Xcode
npx expo run:android   # needs Android Studio
```

Or build in the cloud with EAS, no local Xcode or Android Studio needed: `npx eas-cli@latest build --profile development`.

You can preview the UI in a browser with `npx expo start --web`. Secure storage doesn't work on web, so AI features are off there.

## Project layout

- `src/app/` — screens (Expo Router): `(tabs)/` for Pick, Favorites, Recipes and Settings, plus `results`, `meal/*` and `recipe/*`
- `src/lib/generator.ts` — picks ideas: favorites mix, AI, or built-in library with fallbacks
- `src/lib/ai.ts` — calls the Claude Messages API with structured JSON output
- `src/lib/mealLibrary.ts` — the built-in meals
- `src/lib/store.tsx` — app state, saved on the device with AsyncStorage
